# Pádel Pulgares

Juego de pádel para el móvil y el navegador (Three.js).

- Jugar: https://tonianino.github.io/Padel/
- Pala móvil (prueba, fase 1): abre https://tonianino.github.io/Padel/pala.html en el ordenador y escanea el QR con el móvil.
- Pala móvil en 3D (golpear a una bola que viene): https://tonianino.github.io/Padel/pala3d.html
